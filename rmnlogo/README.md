## Installation

### Homebrew

```sh
brew install remino/remino/rmnlogo
rmnlogo
```

### Download

Go to the
[GitHub download page](https://github.com/remino/rmnlogo/releases/latest) for
the latest release and download the source archive.

### Git clone

```sh
git clone git@github.com:remino/remutils.git
cd remutils/rmnlogo
./rmnlogo
```

## Usage

Run `rmnlogo` to print the logo:

```sh
rmnlogo
```

Show the installed version:

```sh
rmnlogo -v
```
