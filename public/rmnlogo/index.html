rmnlogo

Display the RÉMINO logo in ASCII art and ANSI colours.

2022-2026 Rémino Rem https://remino.net/

  • Installation
    • Homebrew
    • Download

Installation

Homebrew

brew install remino/remino/rmnlogo
rmnlogo

Download

Go to the GitHub download page for the latest release and download the source archive.

Git clone

git clone git@github.com:remino/remutils.git
cd remutils/rmnlogo
./rmnlogo

Usage

Run rmnlogo to print the logo:

rmnlogo

Show the installed version:

rmnlogo -v
