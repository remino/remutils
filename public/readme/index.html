Installation

brew install remino/remino/readme

Or run the script directly from a clone:

git clone git@github.com:remino/remutils.git
cd remutils/readme
./readme

Usage

Run readme to open the README in the current directory. If none exists, it opens the first README found in an immediate child directory. glow is used when available; otherwise, the README opens in less.

Use -l to list all matching README files in that order:

readme -l

Pass a filename or pattern to restrict the search:

readme README.md
readme -l 'README.*'

Run readme -h or man readme for the full reference.
