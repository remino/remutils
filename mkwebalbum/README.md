## Installation

### Homebrew

```sh
brew install remino/remino/mkwebalbum
mkwebalbum -h
```

### Download

Go to the
[GitHub download page](https://github.com/remino/remutils/releases/latest) for
the latest release, and download the source code from there.

### Git clone

```sh
git clone git@github.com:remino/remutils.git
cd remutils/mkwebalbum
./mkwebalbum -h
```

## Usage

Run `mkwebalbum -h` to see the available options. It requires
[ImageMagick](https://imagemagick.org/) to create image previews.
